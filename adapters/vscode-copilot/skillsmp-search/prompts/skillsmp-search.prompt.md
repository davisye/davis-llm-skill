# SkillsMP Search Prompt

Use SkillsMP to find relevant community skills, then summarize the best candidates and call out review steps before adoption.

Checklist:

1. Choose keyword or AI search based on how specific the user's request is.
2. Use one concrete query at a time.
3. Summarize the top matching skills with name, repo, and fit.
4. Separate marketplace discoveries from your own recommendation.
5. Call out that the repository should be reviewed before installation.
