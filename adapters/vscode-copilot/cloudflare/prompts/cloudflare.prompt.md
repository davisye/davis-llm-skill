# Cloudflare Platform Prompt

Help build and deploy applications on the Cloudflare platform. Use decision trees to select the right products and follow best practices for Workers, Pages, storage, and security.

Checklist:

1. Identify the right Cloudflare product for the task.
2. Set up Wrangler configuration.
3. Implement using the appropriate API/SDK.
4. Configure security and networking.
5. Deploy and verify.
