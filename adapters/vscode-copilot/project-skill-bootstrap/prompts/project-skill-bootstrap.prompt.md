# Project Skill Bootstrap Prompt

Detect the repository stack, then generate a project-local skill router and focused stack references.

Checklist:

1. Inspect stable repository files to infer the stack.
2. Select only the domains that fit the project.
3. Generate a routing-oriented root SKILL.md.
4. Generate focused .project-skills/*.md references.
5. Avoid overwriting existing files unless replacement is requested.
