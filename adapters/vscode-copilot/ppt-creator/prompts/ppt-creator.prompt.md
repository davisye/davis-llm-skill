# PPT Creator Prompt

Create a professional slide deck from the given topic. Apply Pyramid Principle, assertion-evidence design, and data visualization best practices.

Checklist:

1. Gather audience and objective information.
2. Structure the story with Pyramid Principle.
3. Create 12-15 slide outline with assertion headings.
4. Select appropriate charts for data points.
5. Generate speaker notes for each slide.
6. Self-evaluate with rubric (score ≥ 75).
7. Package all deliverables.
