# Context7 Docs Prompt

Use Context7 to answer with current, version-specific library documentation and examples.

Checklist:

1. Resolve the library ID unless the prompt already includes one.
2. Prefer official or high-reputation matches.
3. Query for the exact feature, migration, API, or integration pattern.
4. Use a versioned ID when the request is version-sensitive.
5. State the chosen library ID and any assumptions in the answer.
