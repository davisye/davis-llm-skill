# Cloudflare Platform Instructions

Build and deploy on the Cloudflare platform using Workers, Pages, storage, AI, networking, and security services.

- Use decision trees to route to the right Cloudflare product.
- Prefer Workers for serverless compute, Pages for full-stack apps.
- Use D1 for relational data, KV for key-value, R2 for object storage.
- Use Wrangler CLI for local development and deployment.
- Consult product-specific references for detailed API usage.
