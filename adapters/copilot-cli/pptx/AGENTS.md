# PPTX

Create, edit, and analyze PowerPoint (.pptx) files. Support html2pptx workflow for new presentations, OOXML editing for existing ones, and template-based creation.

- Use html2pptx workflow for creating new presentations from scratch.
- Use OOXML unpack/edit/validate/pack workflow for editing existing presentations.
- Use template duplication and replacement workflow for template-based creation.
- Always validate after editing OOXML before packing.
- Create visual thumbnails for template analysis.

## Avoid

- Editing OOXML without validation
- Creating presentations without analyzing content first
- Using template layouts that don't match actual content
- Skipping visual validation after creation
