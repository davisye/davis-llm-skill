# PPT Creator

Create professional slide decks from topics. Generates structured content with data-driven charts, speaker notes, and complete PPTX files using Pyramid Principle and assertion-evidence style.

- Apply Pyramid Principle: conclusion first, then evidence.
- Use assertion-style headings (complete sentences) not topic labels.
- Limit 3-5 bullet points per slide.
- Generate 45-60 second speaker notes per slide.
- Self-evaluate with rubric; refine if score < 75.

## Avoid

- Using topic labels instead of assertion headings
- Packing too much text on a single slide
- Skipping the rubric self-check
- Waffling instead of using structured storytelling
